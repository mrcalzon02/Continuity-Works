Visual rendering/review boundary
--------------------------------
- StructureSmith does not perform server-side visual rendering as part of structure generation.
- fitness.visual_gate is OPTIONAL_CLIENT_REVIEW.
- fitness.visual_review_required is false.
- fitness.visual_review_owner is client.
- fitness.server_side_rendering is false.
- StructureCapability advertises visual_review.required=false and independent_visual_review_required=false.
- Generation provider contracts advertise server_visual_review_required=false, server_side_rendering=false,
  client_rendering_responsibility=true, and visual_review_advisory_only=true.
- StructureForge remains the reference browser-side renderer; other clients render returned geometry/artifacts
  using compute they own if they want visual inspection.
- Absence of a render or visual review does not block StructureSmith generation, validation, snapshotting, or return.
