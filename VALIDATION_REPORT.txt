Authoritative Java decision HTTP transport
------------------------------------------
This cycle added:
modules/continuityworks-api/src/main/java/io/continuityworks/api/blueprint/ContinuityWorksDecisionAuthorityHttpServer.java

The service is deliberately a serialization/session transport around ContinuityWorksDecisionAuthorityAdapter, not a second decision engine. It uses the Java 17 JDK HTTP server and adds no third-party runtime dependency.

Implemented transport surface:
- GET  /v1/health
- GET  /v1/blueprints/decision/profile
- POST /v1/blueprints/decision/begin
- POST /v1/blueprints/decision/next
- POST /v1/blueprints/decision/apply
- POST /v1/blueprints/decision/validate
- POST /v1/blueprints/decision/finalize

Transport integrity behavior:
- request bodies are bounded at 64 KiB by default
- JSON is parsed strictly at the transport boundary
- real BlueprintRequest / ConstructionVolume / site / material / specification records are reconstructed before delegation
- authoritative decision sessions are keyed by request UUID
- begin rejects duplicate live request IDs
- next, apply, validate, and finalize require the supplied state to match the current authoritative session state
- stale, modified, or concurrently superseded snapshots fail closed with HTTP 409 rather than being accepted as authority
- apply delegates to ContinuityWorksDecisionAuthorityAdapter and atomically replaces the session state only after a successful authoritative mutation
- finalize atomically records the finalized authoritative state
- restoreDecision(State) is available as a narrow future persistence/resume seam without changing semantic authority
- no raw world mutation instruction is representable through this service

The listener accepts an optional expected_revision field for direct transports, but the existing Python bridge public contract does not require or advertise that extension. The accepted integration test therefore uses the published state + encoded_mutations contract and verifies stale rejection from authoritative session state itself.
