# Extraction from Infinite Domain

This standalone capability generalizes methods proven useful in Infinite Domain while deliberately removing project-specific assumptions.

Extracted concepts include:

- authoritative generator rather than hand-edited generated asset;
- deterministic NBT serialization and Git-blob hash locking;
- materialize-after-verify CI;
- static integration/deformation validation;
- two-track mechanical vs visual status;
- Heavy Rebuild treating weak geometry as a program diagram;
- real-world functional precedent;
- purpose-driven circulation/rooms/utilities/site infrastructure;
- cultural/institutional design language;
- fixed-camera multi-angle review;
- independent validation and independent visual review;
- immutable/resumable long-running state;
- target-local workers with serialized shared-state integration;
- family-based batch generation and checkpoint waves;
- location/biome/terrain selector ownership;
- sparse, context-aware structure pools;
- incremental one-feature-at-a-time review ledgers.

Project-specific content such as Pelagos, Karsic, OWS IDs, quest IDs and Infinite Domain loot tables belongs in provider/reference examples, not the generic API.

See `reference/infinite_domain/SOURCE_MANIFEST.json` for extraction provenance.
