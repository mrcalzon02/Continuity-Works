# Cultural Theming, Adaptive Purpose, and Institutional Language

A theme is not a block palette.

A complete theme profile can specify:
- massing/silhouette;
- structural rhythm;
- facade hierarchy;
- entrance/security language;
- preferred material roles;
- technology expression;
- utility exposure/concealment;
- interior organization;
- signage/wayfinding;
- exterior infrastructure;
- damage/weathering vocabulary;
- forbidden motifs.

Purpose and culture are separate axes. A hospital and warehouse built by the same culture should share a design language without becoming the same building.

## Purpose grammar

A purpose profile defines:
- actual function, not a vague category;
- required functional zones;
- public/staff/service routes;
- utilities;
- loading/maintenance/waste;
- emergency/secondary egress;
- exterior infrastructure;
- equipment clearances;
- security/access tiers;
- current/ruined/occupied function if different from original.

## Fitness-for-purpose gate

Ask whether a user can infer the function from:
1. approach/site infrastructure;
2. silhouette;
3. circulation;
4. room sequence;
5. operational fixtures/utilities.

Decorative signage alone does not satisfy this gate.
